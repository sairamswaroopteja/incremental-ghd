# Faithfulness ledger

Every point where this implementation reads, completes or departs from Gottlob, Lanzinger, Longo,
Okulmus, *Incremental Updates of Generalized Hypertree Decompositions* (arXiv:2209.10375v1),
recorded in one place. This file is the authority; README and reports must not contradict it.

Rule (project brief §9.9): never silently choose whichever interpretation makes a test pass.
Every entry names a switch in `ighd.common.config.Semantics` (where one exists) and a pinning test.

**Status column.** *decided*: reading fixed, code not yet written. *live*: implemented and pinned.
