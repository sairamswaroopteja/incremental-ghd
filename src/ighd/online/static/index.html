Incremental GHD

An implementation of Gottlob, Lanzinger, Longo and Okulmus, Incremental Updates of Generalized Hypertree Decompositions (arXiv:2209.10375), maintaining a minimum-width generalized hypertree decomposition (GHD) of a hypergraph while you add and remove vertices, edges and equalities.

Hypergraph input

One edge per line: a name, then its vertices, e.g. e1: a b c.

HyperBench syntax also works: e1(a,b,c), e2(c,d).

Blank lines and # / % comments are ignored.

Every answer is exact (the problem is NP-hard), so keep inputs small: a few dozen edges at most. Searches stop after the time limit in Settings.

    About this demo

    This page is a front end for a Python implementation of the paper. The hypergraph and its decomposition are held by the implementation itself: Decompose runs an exact search, and every modification is handed to the incremental update (ghd_update): Algorithm 2 finds the δ-mutable subtree, Algorithms 3–4 create scenes (old nodes that may be reused), and Algorithm 5 rebuilds only what changed. In the decomposition drawing, green nodes were kept from the previous decomposition and purple ones were built anew.

    The hypergraph is drawn with every edge as a coloured shape around exactly its vertices. Edges changed by the last step are dashed. The layout keeps vertices where they were, so after a modification you see the change in a picture you recognise.

    On the number. The paper's update only promises a GHD of width at most the old width, or a proof that none exists. To show ghw itself after every step this demo adds exact searches: upward when the width must rise, and one width smaller when it may have dropped. With no time limit, a value marked proven is exact. A step that hits the time limit says so and is shown as an upper bound, never as proven. Several of the paper's statements needed corrections to be implemented faithfully; see docs/FINAL_REPORT.md.

    Hypergraph and decomposition are computed in Python on this machine (127.0.0.1) and drawn here with plain SVG. No network access is used.
